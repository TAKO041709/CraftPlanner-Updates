# Craft Planner UI Updates

Public metadata and approved UI update packages only.

`latest-ui.json` currently uses version `0.0.0` to disable automatic downloads until a reviewed update is released.

Do not upload installers, private data backups, credentials, or build kits. UI ZIPs contain inspectable HTML/JavaScript and are not private.

Future releases must provide `version`, a public HTTPS ZIP `url`, and the ZIP's 64-character SHA-256 checksum. The ZIP must include a matching `manifest.json` with per-file hashes.
